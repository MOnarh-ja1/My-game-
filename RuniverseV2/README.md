# RUNIVERSE v2 — MgameIO

**Полноценный проект Godot 4.7.2** (GDScript, 3D). Игра Windows 64-bit.

## Что реализовано

- Главное меню, оформленное по утверждённому макету. Наведение на кнопки: плавное увеличение, подсветка и звук.
- Магазин из **50 различных героев** с портретами, уникальными ценами, способностями, покупкой и выбором. Цены 650–8900 монет. Категории и увеличение портрета при наведении.
- Реальный 3D-аватар с процедурной детализацией каждого типа героя, анимацией шагов, рук, прыжка и подката, наклоном и поворотом головы/корпуса в сторону смены дорожки.
- 5 биомов с отдельным ландшафтом, магазин миров, препятствия (ящики/барьеры/низкие ворота), магнит, щит, сундуки, комбо и рывок.
- Способности персонажей влияют на игровую механику (монеты, скорость, прыжки, щит, магнит, рекорд, здоровье, комбо, магазин, рывки и т. д.).
- Сохранение покупок, монет, рекорда и настроек локально.

## Управление

- `A` / `←` — влево; `D` / `→` — вправо
- `Пробел` / `W` / `↑` — прыжок
- `S` / `↓` / `Ctrl` — подкат
- `Shift` — рывок, `Esc` — пауза

## Запуск из Godot

Откройте Godot 4.7.2, импортируйте `project.godot` и нажмите F5. Для сборки Windows установите экспортные шаблоны соответствующей версии и экспортируйте preset **Windows Desktop** в `build/RUNIVERSE.exe`.

GitHub Actions (в файле `.github/workflows/build-v2.yml`) выполняет импорт, smoke-тест и реальную сборку `.exe`, после чего публикует GitHub Release.

Снимки оформления в `assets/ui/` — оригинальные изображения, подготовленные в этой беседе. Проект на Godot/GDScript, не обёртка браузера.
