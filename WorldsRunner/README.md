# МИРЫ НА БЕГУ — бесконечный раннер для Windows

Полноценная офлайн-игра для Windows 10/11 (64 бит). **MiryNaBegu.exe** — настоящий Windows PE32+ исполняемый файл: не HTML-ярлык, не инсталлятор и не требует установленного Godot, Go или .NET.

## Установка и запуск

1. Скачайте `MiryNaBegu.exe`.
2. Запустите файл двойным щелчком на Windows 10/11 x64. Если Windows SmartScreen предупреждает о неизвестном издателе, файл не подписан цифровой подписью; проверяйте источник скачивания перед разрешением запуска.
3. Нажмите «ИГРАТЬ». Игра работает без интернета.

## Управление

- `A` / `D` или стрелки влево/вправо — сменить полосу.
- `W` / стрелка вверх / `Пробел` — подпрыгнуть через низкие ограждения.
- `S` / стрелка вниз — подкат под высокую балку.
- `Esc` / `P` — пауза. `M` на паузе — главное меню.
- В меню нажмите «МАГАЗИН МИРОВ» или `B`; в магазине клавиши `1–5` выбирают/покупают миры.

## Миры

| Мир | Цена в игровых монетах |
| --- | ---: |
| Зелёная долина | бесплатно |
| Песчаное королевство | 80 |
| Снежные вершины | 200 |
| Затерянные джунгли | 420 |
| Вулканический остров | 800 |

Игра содержит один бесплатный мир и четыре покупаемых. Монеты собираются в забегах, покупка не требует настоящих денег. Миры отличаются фонами, растительностью, цветом трассы и атмосферой. Все миры сохраняются после перезапуска. Есть три жизни, ускорение забега, щит, монеты, случайные препятствия и рекорд для каждого мира.

Сохранение: в системной папке конфигурации пользователя `MiryNaBegu/progress.json` (на Windows обычно `%AppData%\\MiryNaBegu\\progress.json`).

## Исходный код и сборка

Код находится в `source/`. Движок — самостоятельная Win32/GDI-игра на Go без внешних зависимостей; это не проект Godot. Такое решение позволяет собрать компактный нативный `.exe` без отдельных данных, библиотек и установки движка.

С Go 1.22 или новее:

```powershell
cd source
$env:GOOS="windows"
$env:GOARCH="amd64"
$env:CGO_ENABLED="0"
go build -trimpath -ldflags="-H windowsgui -s -w" -o ..\MiryNaBegu.exe .
```

Workflow `.github/workflows/build-windows.yml` собирает свежий exe автоматически и публикует его как GitHub Actions artifact.

## Статус проверки

Проект собран кросс-компилятором Go и проверен `go vet`; файл распознан как PE32+ Windows GUI x86-64. Запустить и проверить игру непосредственно в Windows в среде сборки не было возможности. Антивирусы могут дополнительно проверять неподписанные новые исполняемые файлы.
