# DIG & FIND — Native Windows 3D

Самостоятельный Windows EXE. Без Godot, браузера и сторонних DLL.

## Скачать

Откройте вкладку **Actions** в этом репозитории, выберите сборку **DIG AND FIND Windows EXE**, затем скачайте артефакт **DIG_AND_FIND_Windows_EXE**.

## Управление

WASD — ходьба; Shift — быстрее; ПКМ с перемещением мыши — поворот камеры; E / ЛКМ — раскопка; F — очистка находки; 1 — улучшение лопаты; Esc — выход.

## Версия

Технический 3D-прототип с объёмной местностью, деревьями, руинами, раскопками и семью находками. **Графика упрощённая, не фотореалистичная.** На реальном Windows-ПК пока не проверено.

## Сборка вручную

```powershell
go build -trimpath -ldflags="-s -w -H windowsgui" -o DIG_AND_FIND.exe .
```
