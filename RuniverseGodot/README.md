# RUNIVERSE — Миры на бегу

**Настоящая 3D-игра на Godot 4.7.2** для Windows 10/11 x64. Оригинальные низкополигональные модели создаются внутри игрового движка, без платных ресурсов.

## Что есть в игре

- Полноценный бесконечный раннер на трёх дорожках с постепенно растущей скоростью.
- Плавная анимация ног, рук, головы, шарфа и прыжков главного героя.
- Различные трёхмерные препятствия: ящики (обходить), барьеры (перепрыгивать), ворота (подкатываться).
- Монеты, очки, три жизни, рекорды и сохранение в `user://runiverse_save.cfg`.
- **Пять миров с разными цветами, декорациями, дорогами и костюмами**:
  1. Зелёная долина — бесплатно;
  2. Пески времени — 80 монет;
  3. Снежные пики — 200 монет;
  4. Дикие джунгли — 420 монет;
  5. Остров вулканов — 800 монет.
- Магазин миров и сохранение покупок.
- Генерируемые звуковые эффекты, пауза, управление с клавиатуры.

## Управление

| Клавиша | Действие |
|---|---|
| ← / A | Перемещение влево |
| → / D | Перемещение вправо |
| ↑ / W / Пробел | Прыжок |
| ↓ / S / Ctrl | Подкат |
| Esc / P | Пауза |
| M | Отключить / включить звук |
| Enter / R | Новый забег после проигрыша |

## Запуск в редакторе

1. Установить [Godot 4.7.2 Standard](https://godotengine.org/download/windows/).
2. Нажать **Import**, указать файл `project.godot`.
3. Нажать **F5** и играть. Все 3D-модели создаются автоматически при запуске.

## Сборка Windows EXE

Есть готовый пресет экспорта `Windows Desktop` в `export_presets.cfg`. Установить в Godot соответствующие **export templates 4.7.2** и запустить **Project → Export → Windows Desktop → Export Project**.

```sh
godot --headless --path . --editor --import --quit
godot --headless --path . --export-release "Windows Desktop" build/Runiverse.exe
```

При пуше ветки в GitHub запускается `.github/workflows/build-godot.yml`: устанавливает Godot 4.7.2 и его Windows template, проверяет загрузку проекта и экспортирует EXE. Готовый бинарный файл будет доступен в разделе **Actions → Build Godot Runiverse for Windows → Artifacts** после успешной сборки.

> Примечание: проект не использует исходники Subway Surfers и Temple Run. Если Windows SmartScreen предупреждает о неизвестном издателе — это может быть связано с отсутствием цифровой подписи, а не с наличием вредоносного кода.
